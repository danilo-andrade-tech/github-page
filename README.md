## 🚀 Introdução

O **PortfólioHub** é um ecossistema profissional integrado que une quatro plataformas — **Google Sites, GitHub, GitHub Pages e LinkedIn** — em uma infraestrutura coesa para a construção de uma vitrine técnica de alto impacto. O projeto nasceu da necessidade de resolver um problema comum entre desenvolvedores: a fragmentação das informações profissionais entre diferentes plataformas, o que muitas vezes prejudica a percepção de valor por parte de recrutadores.

A proposta central divide as responsabilidades de forma estratégica:
*   **Camada Institucional (No-Code):** O Google Sites cuida da parte de marketing pessoal, identidade visual, certificados e storytelling.
*   **Camada Técnica (Code-Based):** O GitHub e o GitHub Pages atuam como o motor de evidência prática, hospedando o código real e as documentações de engenharia.

A Inteligência Artificial Generativa — especificamente o Gemini — foi utilizada como copiloto de arquitetura e estratégia através do framework **CATR** (Contexto, Atribuição, Tarefa e Restrição).
